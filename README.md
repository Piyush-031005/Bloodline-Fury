# BloodLine Fury

BloodLine Fury is an original AAA fighting game being developed in Unity 6 HDRP.

## Vision

Reality is Information.

Every civilization discovered a different computational truth.

Combat is the collision of incompatible reality models.

## Tech

- Unity 6 HDRP
- Native C#
- Data-Driven Architecture
- Modular Systems
- Future Rollback Multiplayer
- Phone-as-Controller Support
